# 实验一至六内容覆盖核查

核查对象：六份原始课件、课程 MATLAB 脚本和七个原始 `.slx`。按任务、教学例题、建模操作、元件参数和报告记录分别核对，不能用“已有 33 个数值模型”证明全部实验过程已经实现。

## 核查结论

2.1 版没有完整覆盖操作过程。原 Simulink 页面是固定示意图，生成脚本统一使用输入、一个合并后的 Transfer Fcn 和输出记录，不能替代课件的插入模块、分支连线、积分反馈及各环节组合。

本次补充为 38 个数值模型入口和逐章课件清单，并加入可编辑的课程信号模块画布。画布支持插块、移动、参数、端口连线、删除、撤销、结构 JSON、原生建模脚本和 Online 入口。它是课程子集编辑器；原生 Simulink 元件库、仿真与 Scope 仍在用户授权的官方环境中使用。

## 原始模型检查

读取的是 `.slx` 内部 `simulink/systems/*.xml`，不是根据文件名猜测模型。七个原始模型如下：

- 第一章 `simulink_example.slx`：Step、Sum、Gain=2、Integrator、Scope，积分输出反馈到减号输入。
- 第二章 task1：Step、四个不同 Gain、多输入 Scope。
- task2：四个不同时间常数的惯性 Transfer Fcn。
- **task3 存在错误**：分母为 `[0.01]`、`[0.1]`、`[1]`、`[10]`，没有 `s`，实际上是比例块。原件保留，课程模板改用 Gain(K/T)+Integrator，不能把错误原件作为正确积分模板。
- task4：Derivative 与不同负 Gain，包含理想微分。
- task5：积分分支、直通分支、Sum、Gain，不能由一个 Transfer Fcn 的图标替代操作学习。
- task6：Derivative、时间比例 Gain、直通分支、Sum、总 Gain。

原始模型没有电阻、电容、运放等 Simscape 电气块。课件用物理电路推导，再用信号模块等效。网页 R/C 面板实现这一参数映射，不能宣称已经实现完整电气元件仿真。

## 条件与未确认内容

- 第三章目的中有“磁悬浮系统控制器”一句，但课件后续没有对应被控对象、参数或任务。已标为需教师确认，未擅自编造新的磁悬浮实验。
- Online 许可选择只引导跳转，实际使用权限由 MathWorks 验证。本网页无法读取对方登录态、嵌入完整官方编辑器或自动读取个人会话输出。
- 学生记录表只保存学生输入，不用示例填入“实测”栏；静态示例报告不能当作实际完成实验的证据。
- 网页绘图、课程模块编辑、原生 Simulink、物理电路实验是不同完成层次，不能互相冒充。完成清单由学生手动勾选。

## 可复核文件

课件页码与任务元数据在 `backend/coursework.py`；原始拓扑提取器为 `tools/audit_course.py`；课程模块定义与导出器为 `frontend/blocks.js`；画布为 `frontend/BlockEditor.jsx`；工况、R/C 映射及记录表为 `frontend/CourseManual.jsx`。核查过程输出在不提交的 `runtime/course-audit/`。

安装 `requirements-dev.txt` 可重做 PDF 文字/图页读取。网页部署不需要 PyMuPDF 或本机 MATLAB。原生建模验证使用已有授权 MATLAB R2024b，结果与浏览器 DOM 测试分别记录。浏览器视觉检查因自动安全检查不能确认当前 Edge URL 而停止，本次不声称完成了浏览器截图验收。
