# Control Lab 2.0 修复验收

## 问题与修改

章节切换白屏已在 React DOM 回归测试中复现：图表组件卸载时读取已经清空的 `ref.current`，调用 `Plotly.purge(null)` 抛出异常。清理逻辑现保存挂载时的图表节点，并独立处理绘图更新；工作台增加错误恢复界面。

参数字段按实际任务模型显示，固定模型也可修改分子、分母。自定义最终模型时明确禁用不再参与计算的任务参数。输入幅值、输入类型、采样点数可以修改，正弦自动时长可关闭，所有任务支持幅值扫描。Online、框图运行、报告和导出按钮均接入对应操作。

学生模式默认使用平台 SciPy 计算，不调用本机 MATLAB。MATLAB Online 按钮执行复制脚本和打开官方页面；它不自动登录、运行或回传结果。真实 MATLAB/Simulink 接口由可选的授权计算节点提供。
