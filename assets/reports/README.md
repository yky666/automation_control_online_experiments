# 中山大学实验报告样式

这些资源依据用户提供的实验报告样例提取，供本课程工作台导出使用，
不是学校发布的官方空白模板或认证文件。

- `sysu-lab-template.docx`：保留样例的页首信息表、节设置、样式、校徽水印和页码字段。
  原正文、个人信息、批注、自定义 XML、文档元数据和原实验图像均已移除。
- `sysu-report-patterns.json`：样例中的标题、正文、图题和插图段落结构。
- `sysu-wordmark.jpeg` 与 `sysu-seal.png`：样例中的学校标识，仅用于实验报告排版。

提取工具为 `tools/extract_report_template.py`。原始报告保留在用户电脑上，未纳入仓库。
Word 导出以此模板为基础替换槽位，并保留页眉页脚和样式部件；PAGE/NUMPAGES 在打开时刷新。
PDF 使用相同页面尺寸、边距、校徽裁剪、信息栏及淡色水印；采用开源 Noto Serif SC 字体，
其字形和分页可能与安装有宋体/黑体/楷体的 Word 略有不同。
