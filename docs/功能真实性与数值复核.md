## 数值证据

运行 `python tools/verify_browser_numerics.py`（先导出课程静态资源），
Node 调用实际浏览器求解代码，Python 用 SciPy 连续时间 `lsim` 独立对照。
信号模型的参考系数来自 Python 课程模型导出的默认工况，非复用 JS 状态方程。

- 37 个适定信号模型：10001、20001 两档采样，细化后误差不得增加超过 10%
  （另允许 1e-8 的数值舍入量），20001 点的归一化最大误差需小于 2%。
- 17 个课程电路：20001 点，与对应连续模型比较，保留实际反相符号。
  带宽实验按两级有限开环增益运放的传递函数独立推导，不能套用单个理想环节。
- 信号 D/PD 比较带 Tf 的滤波通道；理想阶跃微分没有有限峰值，不纳入该对照。
  电路 D/PD 使用有限上升时间的输入，按解析导数检查，排除起点及导数拐点附近两步。
- 一个非真有理部分分式任务只做代数分析，不伪造时域仿真。

结果见 [机器可读报告](browser-numerical-audit.json)，54 个工况通过，最大细网格
归一化误差约 1.85%。归一化分母为 `max(1, max(abs(reference)))`，
所以该数字不等于每个采样点的相对误差。报告保存源码哈希，检查已接入 CI。

浏览器使用隐式欧拉，临界振荡会受数值阻尼影响，快速系统必须细化采样；
不能仅凭默认粗网格曲线判断稳定性。信号页显示本次实际步长并允许 20001 点。
这些检查覆盖默认课程参数，不证明任意手动编辑网表都正确。

## Simulink / Simscape 边界

网页信号模块与元件电路是实际数值模拟，均可编辑、求解及导出；
网页不是官方 Simulink 或 Simscape 编辑器。
导出的信号脚本建立真实模块和连线，电路脚本建立 Foundation 电气元件。
原生执行需要安装或 Online 账户有相应产品使用权限。

[官方 GitHub 跳转文档](https://www.mathworks.com/help/matlab/matlab_env/open-github-repositories-in-matlab-online.html)
说明链接克隆仓库并打开文件，不等于自动执行当前网页编辑。
[官方 Op-Amp 模型](https://www.mathworks.com/help/simscape/ref/opamp.html)
是理想运放；真实芯片噪声、压摆率等不能从该模型推断。

仓库保留的 37 个原生信号模型和 18 个物理验证模型（17 个课程电路加一个限幅工况）
有历史 R2024b 运行记录。本次机器没有 MATLAB，因此**没有重新执行原生 MATLAB**。
本次也没有可连接的真人浏览器；交互验证是 React DOM 测试，不能冒充真人截图、
MathWorks 登录或许可证验收。需要教师在实际授权环境重跑 `tests/verify_course_simulink.m`
及 `tests/verify_physical.m` 后，才能声称当前原生环境已复验。
