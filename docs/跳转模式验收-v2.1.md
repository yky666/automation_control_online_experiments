# 2.1 MATLAB Online 跳转模式验收

## 功能

默认使用静态代码与结果示例，不请求后台计算、历史记录或报告 API。六章共 33 项任务均可浏览，代码由当前参数生成，图表明确标注为默认参数预计算示例。

确认已有可用 Online 许可后，链接使用 MathWorks 官方 `open/github/v1` 格式，指定本仓库及当前任务 `.m` 文件。每个任务各有 MATLAB 与 Simulink 脚本，共 66 份。当前修改复制到剪贴板；官方打开的仓库文件为默认参数，需要粘贴修改并点击 Run。

许可选择只负责显示跳转入口。本网页没有跨站许可证验证能力，最终登录与可用产品由 MathWorks 处理。无 Online 权限可复制或下载代码，在本地 MATLAB 使用。

参数扫描生成各组脚本，运行时保留不同工况的图窗。示例报告注明来源，不冒充个人实际实验。公开资源排除原有个人实验报告、运行记录和许可证令牌。

## 验证

- 55 项后端与静态资源测试通过。
- 11 项 React DOM 交互测试通过，包括全部 33 项任务切换、许可入口、对应 MATLAB/Simulink 文件跳转、代码修改与示例保持区分，以及已有平台回归。
- 生产构建通过；六章数据可通过本机 2.1.0 服务读取。
- 用本机 MATLAB R2024b 独立构建 33 个脚本模型，与 SciPy 默认示例核对。代数模型按 1e-10 精度核对；超前设计的两个独立裕度求解方法存在数值差异，按 1e-3 相对系数精度核对。实际最大相对系数差为 0.000115134，约 0.0115%。这只验证模型构造，不代表登录了 Online 或自动获取了个人会话结果。

## 使用范围

已提供 GitHub Pages 的手动发布工作流及仓库子路径配置。仓库更新与网站发布是分别进行的操作；工作流完成部署前，不应把预期 Pages 地址当作已经上线的网址。

本次 DOM 测试使用 jsdom 与模拟 Plotly 生命周期，没有自动登录 MathWorks，也没有进行 Edge 截图验收。可选服务端原生计算协议保留供教师后续部署，当前静态学生界面不调用该协议。
